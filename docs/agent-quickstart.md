## Update an existing deck from CSV

Read `numbers.csv`:

```csv
Region,Revenue
North,150
South,175
West,210
```

The chart command accepts comma-separated values or JSON arrays, rather than a CSV filename. Parse the CSV header and rows first; the arguments below are generated from these rows. Use a CSV reader for quoted fields in your own data. Read the chart selector and current point count before editing.

```sh
ooxml pptx charts list --help
```

```sh
ooxml --json pptx charts list deck.pptx
```

```sh
ooxml pptx charts update-data --help
```

```sh
ooxml --json pptx charts update-data deck.pptx --chart chart:1 --series 1 --values-json '["150","175","210"]' --categories-json '["North","South","West"]' --expect-point-count 3 --out numbers-updated.pptx
```

```sh
ooxml --json pptx charts list numbers-updated.pptx
```

Saved chart readback contains values `150, 175, 210` and categories `North, South, West`; the second chart is unchanged. The test also extracts the embedded workbook and verifies the matching cells.

## Append a slide from a Markdown snippet

Write `snippet.md`:

```markdown
# Next quarter

- Expand the pilot
- Review revenue monthly
```

Build the snippet as a one-slide presentation, then import that slide into the existing deck. Use explicit import policies when the source has a different layout or theme. With no insertion flag, `import-slide` appends. Inspect the slide count before and after.

```sh
ooxml pptx slides list --help
```

```sh
ooxml --json pptx slides list numbers-updated.pptx
```

```sh
ooxml pptx build --help
```

```sh
ooxml --json pptx build --from-markdown snippet.md --out snippet.pptx
```

```sh
ooxml pptx slides import-slide --help
```

The original first guess below exits `1` for these fixtures because their layouts differ. It publishes no output. This expected refusal is retained as a diagnostic regression for `ooxml-fqo`:

```sh
ooxml --json pptx slides import-slide numbers-updated.pptx --source snippet.pptx --slide 1 --out expanded.pptx
```

Recover using the explicit policies documented by help and the refusal message:

```sh
ooxml --json pptx slides import-slide numbers-updated.pptx --layout-policy import --theme-policy import --source snippet.pptx --slide 1 --out expanded.pptx
```

```sh
ooxml --json pptx slides list expanded.pptx
```

```sh
ooxml pptx slides show --help
```

```sh
ooxml --json pptx slides show expanded.pptx --slide 3 --include-text
```

```sh
ooxml --json pptx charts list expanded.pptx
```

Saved readback shows three slides, the snippet title and both bullets on the final slide, and unchanged chart data on the existing slides.

## Fix dangling document styles

Inspect the report, then use the one-call remediation loop. The seeded report exits `5` because it references an undefined style; that exit is expected for the initial check. Inspect the returned findings before choosing a fix.

```sh
ooxml check --help
```

```sh
ooxml --json check report.docx --openxml-sdk skip
```

```sh
ooxml --json check report.docx --fix --out repaired.docx --openxml-sdk skip
```

```sh
ooxml --json check repaired.docx --openxml-sdk skip
```

The saved document passes check with zero findings. The original report stays unchanged. `--openxml-sdk skip` keeps this editing loop independent of optional local tools; run schema proof separately when available.

## Add a chart to an existing workbook

Use `charts create` to add a chart. Read the sheet and source range first, then confirm the new chart and unchanged worksheet values.

```sh
ooxml xlsx sheets list --help
```

```sh
ooxml --json xlsx sheets list workbook.xlsx
```

```sh
ooxml xlsx ranges export --help
```

```sh
ooxml --json xlsx ranges export workbook.xlsx --sheet Data --range A1:B4 --include-types
```

```sh
ooxml xlsx charts list --help
```

```sh
ooxml --json xlsx charts list workbook.xlsx
```

```sh
ooxml xlsx charts create --help
```

```sh
ooxml --json xlsx charts create workbook.xlsx --sheet Data --type line --range A1:B4 --title 'Revenue trend' --anchor L2 --out charted.xlsx
```

```sh
ooxml --json xlsx charts list charted.xlsx
```

```sh
ooxml --json xlsx ranges export charted.xlsx --sheet Data --range A1:B4 --include-types
```

Saved readback shows two charts, including the new line chart with values `100, 120, 90`. The worksheet values and cell types are unchanged.
